# Privacy Policy — Blox Fruits Giveaways and Services' Guardian

**Last Updated:** October 2026

---

## 1. What Data We Collect

Blox Fruits Giveaways and Services' Guardian ("the Bot") collects and stores the following data when you use the server or interact with the Bot:

- **User ID and Guild ID** — to link data to you and to the correct server
- **Economy data** — gem balance, bank balance, daily/weekly claim times, bounties and lottery tickets
- **Moderation records** — warnings (reason, staff member, time), and jail records (your roles before jail, the reason and the release time)
- **Giveaway data** — which giveaways you joined
- **Invite data** — who invited each member and how many members each person has invited (stored by user ID), used to give invite milestone roles
- **Birthday** — day and month only, and only if you set it
- **Reminders and AFK** — reminder text, channel and time; AFK status and reason
- **Counting** — the last person who counted in the counting channel
- **First use** — the date you first used a slash command
- **Staff records** — for staff members only: staff performance ratings and notes

**Message content:** the Bot reads messages to process commands, counting, the bad word filter and the automatic FAQ replies. Message content is not stored by the Bot. If the bad word filter removes a message, a report that includes the flagged word and the message text is posted in a private staff log channel on Discord.

**Server logs:** the Bot posts logs (for example warnings, kicks, bans, jail, bad word reports, invite role changes) in private staff channels on Discord. These are Discord messages and are kept according to the server's own rules.

We do **not** collect email addresses, passwords, payment details or any data outside of Discord.

---

## 2. How We Use Your Data

Your data is used solely to operate bot features:

| Data | Purpose |
|---|---|
| User ID + balance | Economy system (gems, bank, shop, leaderboard) |
| User ID + warnings / jail record | Moderation (warn, mute, ban escalation, jail and release) |
| User ID + giveaway entries | Running giveaways and picking winners |
| User ID + birthday | Birthday wish on the correct date |
| User ID + reminder | Sending reminders at the scheduled time |
| AFK status | Notifying others when you're mentioned |
| User ID + invite count | Giving invite milestone roles |
| First-use date | Sending a welcome message the first time you use a command |

---

## 3. Data Storage

Data is stored in files on the cloud hosting service that runs the Bot. It is **not** sold, used for advertising, or shared with anyone other than the hosting service that stores it and Discord itself (which processes all messages under its own [Privacy Policy](https://discord.com/privacy)). The Bot's owner and server staff can access the stored data in order to run and moderate the server.

---

## 4. Data Retention

- Economy data and giveaway records persist while the Bot is in use. Giveaway records are kept after a giveaway ends.
- Warnings are kept while you remain in the server. **Warnings are deleted automatically when you leave the server.**
- Jail records are deleted when you are released.
- Invite counts persist while invite tracking is in use. The record of who invited you is removed when you leave the server.
- Reminders are deleted after they fire.
- You can remove your own birthday at any time with `/birthdayremove` or `!birthdayremove`.

---

## 5. Your Rights

You may request deletion of your data at any time by opening a ticket in the server. We will remove your economy balance, warnings, and any other data stored about you upon request.

---

## 6. Age

The Bot is not intended for anyone under the minimum age required by Discord. Do not use the Bot if you do not meet Discord's age requirements.

---

## 7. Changes

This policy may be updated occasionally. Continued use of the Bot after changes constitutes acceptance.
